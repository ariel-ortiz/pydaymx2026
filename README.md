## Resumen

Los desarrolladores modernos de Python suelen tratar el procesamiento de imágenes como una caja negra, confiando en bibliotecas de alto nivel para cambiar el tamaño, filtrar o codificar datos. Aunque este enfoque es eficiente, dicha abstracción oculta los fascinantes fundamentos matemáticos de los medios digitales. Este charla elimina esas capas para enseñarte a manipular imágenes interactuando con su elemento más fundamental: el píxel individual.

Utilizando la biblioteca de imágenes Pillow como un puente ligero para gestionar la entrada y salida de archivos (I/O), dejaremos de lado sus métodos automatizados para implementar nuestros propios algoritmos desde cero. Trataremos las imágenes como cuadrículas puras de datos numéricos, aprendiendo a recorrerlas y transformarlas utilizando la lógica nativa de Python.

Lo que descubrirás en esta charla incluye:

- Sombras de gris: Escribe las operaciones matemáticas para convertir píxeles de color en valores de escala de grises.
- Esteganografía: Oculta mensajes secretos dentro de una imagen alterando sutilmente los píxeles con datos ocultos; invisibles a la vista, pero accesibles para tu código
- La geometría del escalado: Desarrolla la lógica para mapear coordenadas de píxeles y cambiar el tamaño de una imagen.

Convertirás fotos ordinarias en arte digital creativo y mensajes ocultos dignos de “historias de espías” para divertirte. Y obtendrás un beneficio al adquirir una comprensión profunda y de bajo nivel sobre la manipulación de datos, lo que te convertirá en un programador más versátil y con mayor capacidad para resolver problemas.
